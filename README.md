# Русские субтитры для Adobe Premiere Pro

Локальное распознавание русской речи прямо из открытого эпизода Premiere. Обычные редактируемые субтитры, анимированная графика и собственные MOGRT.

## Скачать и установить

**[Скачать установщик для Windows](https://github.com/koych77/premiere-russian-captions/releases/latest/download/RussianCaptions-Setup.exe)**

1. Сохрани проекты и закрой Premiere.
2. Запусти `RussianCaptions-Setup.exe` и нажми «Установить».
3. Дождись завершения. При первой установке автоматически загрузится модель распознавания — около 1,6 ГБ.
4. Открой Premiere → **Окно → Расширения → Русские субтитры**.

Python и библиотеки включены. Установка для текущего пользователя, без ручного копирования файлов и без прав администратора. После установки распознавание работает без интернета. NVIDIA используется автоматически, если доступна; можно выбрать процессор.

Windows 10/11 x64, Premiere Pro 2025/2026 с поддержкой CEP. Основные функции проверены на Premiere Pro 26. Для установки выдели около 8 ГБ свободного места, включая временные файлы. Первый запуск и работа на CPU могут занимать несколько минут.

Установщик пока без коммерческой цифровой подписи: Windows может показать предупреждение о неизвестном издателе. Скачивай файл со страницы релизов этого репозитория. `SHA256SUMS.txt` содержит контрольную сумму.

## Обновления

Открой шестерёнку в панели → **Обновления**. Плагин проверяет новые стабильные версии раз в сутки; автоматическую проверку можно отключить.

Нажми **Скачать обновление**, затем **Открыть установщик**. Сохрани проекты и закрой Premiere. Установщик обновит программу, сохранив настройки, тексты, собственные стили и уже загруженную модель. Загрузка проверяется по SHA-256, полученному от GitHub. Установщик не закрывает Premiere самостоятельно.

**[Все версии и описание изменений](https://github.com/koych77/premiere-russian-captions/releases)**

## Как пользоваться

1. Открой нужный эпизод. Его название и проект появятся наверху панели.
2. В настройках выбери **Весь эпизод** или **Область In / Out** и нажми **Распознать речь**. В режиме всего эпизода положение курсора не влияет на начало и конец субтитров.
3. Выбери задачу сверху: **Субтитры**, **Анимация**, **MOGRT** или **Титры**. У каждого раздела свои настройки.
4. Проверь текст. **Настройки текста** открывает знаки препинания, регистр и разбиение на всю площадь панели.
5. Нажми **Добавить на таймлайн**. Кнопка **?** объясняет, где редактировать выбранный результат.

| Результат | Что создаётся | Где редактировать |
|---|---|---|
| Обычные субтитры Premiere | Новая дорожка C1/C2 | Текст — в панели «Текст»; оформление — «Свойства» |
| Анимированная графика | Прозрачный MOV | Изменить в плагине и применить снова |
| Шаблоны MOGRT | Отдельные шаблоны с текстом | В свойствах шаблонов Premiere |

В редакторе выбери фразу → **Слова и тайминг**. Первое слово можно перенести к предыдущей фразе, последнее — к следующей, сохранив точные тайминги. Кнопка **Отменить перенос** возвращает последнее перемещение в открытом редакторе. Перенос слова из середины запрещён, чтобы не менять порядок речи. Разделение и объединение целых фраз также доступны.

В «Анимации» есть текст, библиотека стилей, избранное и полноразмерные окна **Шрифт** и **Движение**. Предпросмотр находится только в окне движения раздела «Анимация». В шестерёнке можно включить **Только отмеченные фразы** для акцентов. «Титры» создаёт собственный текст в позиции курсора.

Каталог установленных шрифтов обновляется автоматически и вручную. В разделе MOGRT выбор шаблона открывает его текстовые поля на всю панель. MOGRT использует оформление автора; совместимость зависит от доступности его текстовых полей.

Файлы сессии и графика сохраняются в папке **Русские субтитры** рядом с проектом. Не удаляй её, пока проект использует результаты. Настройки панели находятся в `%LOCALAPPDATA%\Programs\RussianSubtitles\premiere-panel`.

Повторное применение обычных captions создаёт новую дорожку. Изменения из Premiere обратно в редактор плагина не синхронизируются. После изменения звукового монтажа нужно новое распознавание. Автоматический текст требует проверки.

## Удаление

Windows → Параметры → Приложения → **Русские субтитры для Premiere**.
Удаляются файлы программы; сессии, настройки и модель сохраняются. Чтобы удалить их полностью, после удаления программы убери `%LOCALAPPDATA%\Programs\RussianSubtitles`. Файлы рядом с проектами удаляй отдельно, когда они больше не нужны.

Это независимая CEP-панель. Она не изменяет штатную транскрибацию или лицензирование Adobe. Для загрузки локальной CEP-панели установщик включает `PlayerDebugMode` в пользовательских настройках Adobe CSXS 11–13; при удалении общая настройка сохраняется для других расширений.

## Разработка и выпуск версии

- `panel.js`, `host.jsx` — панель и работа с Premiere.
- `engine/` — локальное распознавание и рендеринг прозрачного видео.
- `installer/` — Inno Setup, зафиксированные зависимости и контрольные суммы модели.
- `updater.js`, `updates-ui.js` — проверка и загрузка обновлений.
- `.github/workflows/release.yml` — автоматическая сборка установщика.

Для нового выпуска обнови версию в `release.json`, `CSXS/manifest.xml`, `installer/setup.iss` и `index.html`, затем `RELEASE-NOTES.md`. Создай и отправь тег, например `v3.1.1`. GitHub Actions соберёт установщик и опубликует релиз с постоянной ссылкой на скачивание. Для пробной сборки без публикации запусти workflow вручную на вкладке Actions.

Локальная сборка: Windows x64, Python 3.11, Inno Setup 6.4+. Запусти `python scripts/build.py`, затем `ISCC installer/setup.iss`. Используй чистую папку `build/payload`. Python берётся с python.org, зависимости — из PyPI; модель загружается установщиком с Hugging Face по закреплённой ревизии и SHA-256.

Проверки: `node tests/updater.test.cjs`, `node tests/text-options.test.cjs`, `node tests/cursor-range.test.cjs`, `node tests/word-transfer.test.cjs`, `build/payload/runtime/python.exe tests/test_renderer.py`.
