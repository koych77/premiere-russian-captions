# Русские субтитры для Adobe Premiere Pro

Локальное распознавание русской речи прямо из открытого эпизода Premiere. Два результата: обычные редактируемые субтитры Premiere и собственные MOGRT.

## Скачать и установить

**[Скачать установщик для Windows](https://github.com/koych77/premiere-russian-captions/releases/latest/download/RussianCaptions-Setup.exe)**

1. Сохрани проекты и закрой Premiere.
2. Запусти `RussianCaptions-Setup.exe` и нажми «Установить».
3. Дождись завершения. При первой установке автоматически загрузится модель распознавания — около 1,6 ГБ.
4. Открой Premiere → **Окно → Расширения → Русские субтитры**.

Python и библиотеки включены. Установка для текущего пользователя, без ручного копирования файлов и без прав администратора. После установки распознавание работает без интернета. NVIDIA используется автоматически, если доступна; можно выбрать процессор.

Windows 10/11 x64, Premiere Pro 2025/2026 с поддержкой CEP. Основные функции проверены на Premiere Pro 26. Для установки выдели около 8 ГБ свободного места, включая временные файлы. Первый запуск и работа на CPU могут занимать несколько минут.

Установщик пока без коммерческой цифровой подписи: Windows может показать предупреждение о неизвестном издателе. Скачивай файл со страницы релизов этого репозитория. `SHA256SUMS.txt` содержит контрольную сумму.

## Обновления

Открой шестерёнку в панели → **Обновления**. Плагин проверяет новые стабильные версии раз в сутки; автоматическую проверку можно отключить.

Нажми **Скачать обновление**, затем **Открыть установщик**. Сохрани проекты и закрой Premiere. Установщик обновит программу, сохранив настройки, тексты и уже загруженную модель. Загрузка проверяется по SHA-256, полученному от GitHub. Установщик не закрывает Premiere самостоятельно.

**[Все версии и описание изменений](https://github.com/koych77/premiere-russian-captions/releases)**

## Как пользоваться

1. Открой нужный эпизод: название и проект определятся автоматически.
2. Выбери **Субтитры**, настрой максимум слов, одну или две строки, паузы, пунктуацию и регистр. Можно выбрать сохранённый пресет текста.
3. Нажми **Распознавание → Распознать и создать субтитры**. По умолчанию обрабатывается весь эпизод на русском, независимо от курсора. Результат сразу добавляется на новую дорожку Premiere.
4. Включённое разделение говорящих запускает локальные модели: фразы с разными метками голоса не объединяются. Музыка, похожие голоса и одновременная речь могут снижать точность; разделение и текст требуют проверки.
5. Правь текст в основном редакторе. Выдели первые или последние слова и перенеси к соседней фразе. Поставь курсор между словами и нажми **Разделить здесь**. **Ctrl+Z / Ctrl+Shift+Z** отменяют/повторяют изменения в панели, включая тайминги. Enter задаёт ручной перенос строки для двухстрочного режима.

**Правки панели и Premiere независимы.** Текущий API Adobe не поддерживает чтение/изменение текста и оформления существующих обычных субтитров. Автосинхронизация, замена дорожки, единая с Premiere история отмены и снятие стиля с выбранного субтитра не реализованы. После правок панели можно создать новую дорожку; при повторной генерации показывается выбор создания новой дорожки или отмены. Старая дорожка и её ручные изменения сохраняются. Это ограничение относится к обычным captions, а не к MOGRT.

**Стили и пресеты:** настройки текста сохраняются в общую библиотеку и запоминаются для проекта. Для оформления экспортируй родной стиль Premiere в `.prtextstyle`, сохрани его в библиотеку плагина под своим названием и форматом **Вертикальный / Горизонтальный**. Можно обновить вариант или создать новый стиль. Команда импорта добавляет файл в Premiere; применить его ко всей дорожке нужно в **Свойства → Стиль дорожки**. Выбор файла в библиотеке сам по себе оформление дорожки не меняет. Параметры, которые сохраняет родной стиль, определяются Premiere; положение и размер необходимо проверить отдельно для каждого формата.

| Результат | Что создаётся | Где редактировать |
|---|---|---|
| Обычные субтитры Premiere | Новая дорожка C1/C2 | Текст — «Текст»; оформление — «Свойства» |
| Шаблоны MOGRT | Отдельные шаблоны с текстом | Свойства шаблонов Premiere |

В **MOGRT** нажми **Выбрать шаблон**, затем выбери его текстовое поле. Источник **Распознанные фразы** создаёт MOGRT по таймкодам речи. Источник **Свой текст** создаёт один шаблон в позиции курсора с заданной длительностью. Ручной текст не заменяет распознанные фразы.

Шрифт, цвет и анимация настраиваются в свойствах Premiere или самого MOGRT. Встроенные стили и генерация прозрачного видео убраны из панели. Старые сессии открываются как обычные субтитры; уже созданная графика и файлы проектов сохраняются. Разбиение использует максимум слов, паузы и смену говорящего; ограничений по числу символов и скрытой длительности нет.

MOGRT использует оформление автора; совместимость зависит от доступности его текстовых полей.

Файлы сессии и графика сохраняются в папке **Русские субтитры** рядом с проектом. Не удаляй её, пока проект использует результаты. Настройки панели находятся в `%LOCALAPPDATA%\Programs\RussianSubtitles\premiere-panel`.

Повторное применение обычных captions создаёт новую дорожку. Изменения из Premiere обратно в редактор плагина не синхронизируются. После изменения звукового монтажа нужно новое распознавание. Автоматический текст требует проверки.

## Удаление

Windows → Параметры → Приложения → **Русские субтитры для Premiere**.
Удаляются файлы программы; сессии, настройки и модель сохраняются. Чтобы удалить их полностью, после удаления программы убери `%LOCALAPPDATA%\Programs\RussianSubtitles`. Файлы рядом с проектами удаляй отдельно, когда они больше не нужны.

Это независимая CEP-панель. Она не изменяет штатную транскрибацию или лицензирование Adobe. Для загрузки локальной CEP-панели установщик включает `PlayerDebugMode` в пользовательских настройках Adobe CSXS 11–13; при удалении общая настройка сохраняется для других расширений.

## Разработка и выпуск версии

- `panel.js`, `host.jsx` — панель и работа с Premiere.
- `engine/` — локальное распознавание; сохранены компоненты прежних версий.
- `installer/` — Inno Setup, зафиксированные зависимости и контрольные суммы модели.
- `updater.js`, `updates-ui.js` — проверка и загрузка обновлений.
- `.github/workflows/release.yml` — автоматическая сборка установщика.

Для нового выпуска обнови версию в `release.json`, `CSXS/manifest.xml`, `installer/setup.iss` и `index.html`, затем `RELEASE-NOTES.md`. Создай и отправь тег, например `v3.1.1`. GitHub Actions соберёт установщик и опубликует релиз с постоянной ссылкой на скачивание. Для пробной сборки без публикации запусти workflow вручную на вкладке Actions.

Локальная сборка: Windows x64, Python 3.11, Inno Setup 6.4+. Запусти `python scripts/build.py`, затем `ISCC installer/setup.iss`. Используй чистую папку `build/payload`. Python берётся с python.org, зависимости — из PyPI; модель Whisper загружается установщиком с Hugging Face по закреплённой ревизии и SHA-256. Модели говорящих включены в установщик; сборка загружает их из публичного релиза sherpa-onnx и проверяет SHA-256.

Проверки: `node tests/updater.test.cjs`, `node tests/text-options.test.cjs`, `node tests/cursor-range.test.cjs`, `node tests/word-transfer.test.cjs`, `node tests/output-workflows.test.cjs`, `build/payload/runtime/python.exe tests/test_renderer.py`.
