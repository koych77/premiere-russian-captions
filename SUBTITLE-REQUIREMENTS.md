# Согласованный раздел «Субтитры»

Состояние реализации: 3.4.0. Это не утверждение о выполнении всех требований.

## Реализовано

- Весь монтаж по умолчанию, независимо от позиции курсора; дополнительный In/Out.
- Русский по умолчанию, другие языки/автоопределение; дословное распознавание без очистки слов-паразитов.
- Автоматическое создание новой обычной дорожки после распознавания.
- Локальные модели определения говорящих; границы разных меток разделяют фразы. Результат модели вероятностный.
- Максимум слов, одна/две строки, ручной перенос строки, порог паузы. Нет добавленной задержки после речи.
- Карточки регистра и независимая пунктуация.
- Перенос выбранных граничных слов, разделение между словами и объединение в основном редакторе.
- Ctrl+Z/Ctrl+Shift+Z в панели. Новые слова получают приблизительное время; неизменённые сохраняют своё.
- Общие пресеты текста; настройки и выбранный пресет сохраняются для проекта.
- Общая библиотека экспортированных файлов стиля Premiere с вертикальным и горизонтальным вариантами; обновление варианта/новый стиль.

## Остаётся заблокировано текущим API Premiere

- Автоматическая двусторонняя синхронизация текста и таймингов с существующей дорожкой; последнее изменение побеждает без диалогов.
- Изменение существующей дорожки при повторной генерации.
- Отмена действий плагина и Premiere одной общей историей Ctrl+Z.
- Снятие оформления с выбранного обычного субтитра, сохранение всех его параметров и автоматическое применение ко всей дорожке.

Ограничение подтверждено Adobe: https://forums.creativeclouddeveloper.com/t/caption-track-editing-eta-text-style-labels/12405 и https://developer.adobe.com/premiere-pro/uxp/ppro-reference/classes/captiontrack .

3.4.0 не подменяет эти требования автоматическим созданием дублирующих дорожек при каждом вводе. Для правок доступно явное создание новой дорожки; исходная сохраняется. Стили передаются через .prtextstyle и применяются пользователем в свойствах Premiere. Для полного выполнения нужен поддерживаемый Adobe доступ к обычным captions либо отдельно согласованное изменение архитектуры.
