Установка для Windows: скачайте **RussianCaptions-Setup.exe**, сохраните проекты и закройте Premiere, затем запустите установщик.

При первой установке автоматически загружается модель распознавания (около 1,6 ГБ). Python, библиотеки и поддержка NVIDIA включены. После установки интернет для распознавания не нужен.

Открыть панель: **Окно → Расширения → Русские субтитры**.

В версии 3.3.0:
- Два раздела сверху: Субтитры и MOGRT.
- Убраны встроенные стили, предпросмотр и генерация прозрачного видео. Оформление редактируется в Premiere или свойствах MOGRT.
- Свой текст и длительность перенесены внутрь MOGRT как альтернативный источник текста.
- Одно окно распознавания с диапазоном и устройством; одна точка входа внизу панели.
- Убраны повторяющиеся строки фраз и настройки оформления.
- Сохранены пунктуация, регистр, разбиение, поиск, редактор слов и отмена переноса.
- Старые сессии анимации открываются как обычные субтитры. Существующая графика и файлы проектов не удаляются.

Windows x64, Premiere Pro 2025/2026 с поддержкой CEP. Основные функции проверены на Premiere Pro 26. Установщик не подписан коммерческим сертификатом; Windows может показать предупреждение о неизвестном издателе.
