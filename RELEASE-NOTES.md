Установка для Windows: скачайте **RussianCaptions-Setup.exe**, сохраните проекты и закройте Premiere, затем запустите установщик.

При первой установке автоматически загружается модель распознавания (около 1,6 ГБ). Python, библиотеки и поддержка NVIDIA включены. После установки интернет для распознавания не нужен.

Открыть панель: **Окно → Расширения → Русские субтитры**.

В версии 3.2.1:
- Четыре задачи сверху: Субтитры, Анимация, MOGRT и Титры.
- Настройки текста, шрифта, движения и полей MOGRT открываются на всю панель.
- Редактор фразы с выбором отдельных слов: перенос первого слова к предыдущей фразе или последнего к следующей, с точными таймингами и отменой.
- Предпросмотр только в настройках движения раздела «Анимация».
- Более крупные образцы стилей; кнопки избранного не перекрывают образец.
- На маленькой высоте содержимое прокручивается вместо сжатия полей в узкие полосы.
- Поиск показывает совпадения прямо в своём окне и открывает редактор выбранной фразы.
- Сохранены установка, обновления, системные шрифты и локальное распознавание.

Windows x64, Premiere Pro 2025/2026 с поддержкой CEP. Основные функции проверены на Premiere Pro 26. Установщик не подписан коммерческим сертификатом; Windows может показать предупреждение о неизвестном издателе.
