Установка для Windows: скачайте **RussianCaptions-Setup.exe**, сохраните проекты и закройте Premiere, затем запустите установщик.

В версии 3.4.0:
- Перенос одного или нескольких граничных слов, разделение и объединение прямо в основном редакторе.
- Ctrl+Z / Ctrl+Shift+Z для правок панели; неизменённые слова сохраняют исходные тайминги.
- Максимум слов, одна/две строки, ручной перенос строки и настраиваемое разделение по паузам.
- Карточки регистра с примерами и независимая настройка пунктуации.
- Общая библиотека пресетов текста с сохранением выбора и настроек для проекта.
- Автоматическое создание обычных субтитров после распознавания, русский по умолчанию и выбор языка.
- Локальное определение смены говорящих. Модели включены в установщик; звук не отправляется в интернет.
- Библиотека файлов `.prtextstyle` с отдельными вертикальными и горизонтальными вариантами.

**Ограничения:** автосинхронизация с правками Premiere, замена существующей дорожки, единая история отмены и сохранение стиля прямо из выделенного субтитра недоступны через текущий API Adobe и не реализованы. Правки панели требуют создания новой дорожки. Стиль нужно экспортировать из Premiere в `.prtextstyle`, затем можно сохранить его в библиотеке плагина; после импорта применение выполняется в свойствах Premiere. Разделение говорящих и распознавание не гарантируют безошибочный результат.

При первой установке загружается модель Whisper (около 1,6 ГБ). Python, библиотеки, поддержка NVIDIA и модели говорящих включены. После установки распознавание работает без интернета.

Панель: **Окно → Расширения → Русские субтитры**. Windows x64, Premiere Pro 2025/2026 с поддержкой CEP. Установщик не подписан коммерческим сертификатом.
